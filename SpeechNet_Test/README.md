# SpeechNet_Test — one fixture per experiment

Prepared 2026-10-12. Every on-device experiment of the SpeechNet fine-tuning project has its fixture
here, under one naming scheme, generated by one script (`scripts/export_fixtures.sh`) and checked
against the fixture the original experiment ran on (`scripts/crosscheck.py`, result in
`logs/crosscheck.txt`).

## Cell, weights, hyper-parameters

- Subject S01, condition vocalized, held-out session 3 (fold 3).
- Fine-tuning data: 54 windows of session 3 batch 1 (30 %, 6 per class, stratified, seed 42, drawn
  by the exporter). Evaluation data: all 180 windows of batch 2.
- Pretrained weights: `TrainDeeploy/SpeechNet_Test/pretrained/inter_session_ft/S01/vocalized/speechnet/w1400ms/model_1/leave_one_session_out_fold_3.pt`
  `pretrained/inter_session_ft/` is a copy of the SilentWear `artifacts_reference` checkpoints for all four
  subjects (S01–S04) and both conditions, with each run's `cv_summary.csv`, `run_cfg.json` and the
  fine-tuning reference table `ft_config_0/ft_summary.csv`. The fixtures in this folder already contain
  the windows and weights they need; the checkpoint is used to re-export fixtures and as `--base-ckpt`
  when extracting trained weights from a device run.
  (the paper-matching checkpoint; never the stale `artifacts/` tree).
- Hyper-parameters are those of the correct-weight round-1 experiments
  (`DeeployTest/experiments/deliverable/exp17`, `exp18`, `exp19`):

| method | lr | n_accum | round 1 | other |
|---|---|---|---|---|
| BP | 3e-4 (SGD, accumulation SUMS) | 4 | 40 epochs = 540 steps = 2160 forward+backward | full model, frozen BN statistics, MaxPool argmax mask |
| ZO (MeZO, fp32) | 3e-6 | 4 | 200 epochs = 2700 steps = 21,600 forwards | ε 0.01, Rademacher, seed 42, q 1 |
| QZO (int8 convs) | 1e-5 | 4 | not generated here (see below) | ε 0.01, pooled@99.99 calibration in `calibration/` |

## Naming

`speechnet_<role>_<method>_<variant>` for the training-loop fixtures, `speechnet_<fused|unfused>_b0_<engine>`
for the block-0 convolution kernels.

- `train` = the graph the device runs per step. BP: forward + backward. ZO/QZO: the perturbed forward.
- `optimizer` (BP) / `update` (ZO, QZO) = the weight-update graph. The BP runner finds `optimizer` by
  replacing `_train` with `_optimizer` in the directory name; the ZO runner takes `--optimizer-dir`.
- `infer` = the batch-2 evaluation graph (180 windows) carrying the device-trained weights of round 1.
- `cluster` = the block-0 conv on the cluster cores (runs on Siracusa and on the GAP9 cluster);
  `NE16` = on the GAP9 NE16 accelerator.

The kernel fixtures are hand-built because Onnx4Deeploy has no lowering to the fused or NE16 nodes
yet; all four derive from block 0 of the exp19 QZO fixture (same weights and calibration).

The evaluation fixtures depend on the trained weights. Those here carry the device weight dumps of
exp17 (BP) and exp18 (ZO). After a new device round, extract its `[WDUMP]` lines into a carry
checkpoint (`experiments/exp1/ondevice_sim_S01_fold3/extract_device_weights.py` for BP,
`experiments/deliverable/exp5_ZO_round1/extract_zo_weights.py` for ZO) and re-run `bp_infer` /
`zo_infer` in `scripts/export_fixtures.sh` with that checkpoint.

Note on the GAP9 unfused run: its generated code differs from exp6's only in the L1 offsets of two
buffers (the weight and the requant bias swap places). The tiler's default search strategy
`random-max` is randomised, so the placement can change from build to build; the 0.16 % cycle
difference comes from that placement, and the outputs are bit-exact in both. The round-1 fixtures
were not run (hours each); they are byte-identical to the fixtures exp17 and exp18 ran on.
The BP single step needs `--num-data-inputs 2`: the BP runner infers the per-window input count from
the second window's entries, which a one-window fixture does not have.

jobs `siracusa-speechnet-zo-single-step` and `siracusa-speechnet-qzo-block0-kernels`):

| `SpeechNet_QZO_single_step` | `speechnet_{train,update}_QZO_single_step` | same |
| `SpeechNet_unfused_b0_cluster` | `speechnet_unfused_b0_cluster` | int8 output exact (`Errors: 0 out of 78512`) |
| `SpeechNet_fused_b0_cluster` | `speechnet_fused_b0_cluster` | int8 output exact (`Errors: 0 out of 157024`) |

The cycle counts are written to the workflow run summary but do not gate: the tiler's randomised
placement moves them by up to about 1.5 % between builds. The test lists are `ZO_SINGLE_STEP_TESTS` and
`QZO_BLOCK0_KERNEL_TESTS` in `DeeployTest/test_siracusa_tiled_config.py`, the tests
`test_siracusa_tiled_zo_single_step` / `test_siracusa_tiled_qzo_block0_kernels` in
`DeeployTest/test_platforms.py`. Run them locally (container `traindeeploy`, in `DeeployTest/`):

```bash
python3 -m pytest test_platforms.py -v -m "siracusa_tiled and (zo_training or qzo_block0)"
```

## How to run each experiment

Containers and conventions as in `HandoverDocuments/00_Overview.md`. Kill orphaned simulators first
(`pgrep -f "[g]vsoc_launcher" | xargs -r kill -9`). Paths below are relative to `DeeployTest/`.

```bash
# --- Siracusa: docker exec -it traindeeploy bash ; cd /app/ETH/TrainDeeploy/DeeployTest
M="--l1 128000 --defaultMemLevel L2 --memAllocStrategy MiniMalloc --searchStrategy random-max --cores 8"

# 1  BP round 1 (540 steps; multi-hour), then dump weights and evaluate batch 2
python3 deeployTrainingRunner_tiled_siracusa.py -t ../SpeechNet_Test/speechnet_train_BP_round1 \
  --n-steps 540 --n-accum 4 --l2 1500000 $M -D DUMP_WEIGHTS=ON BN_FROZEN_STATS=ON
python3 experiments/headonly_ondevice_finetune/speechnet_accuracy_eval_untiled.py \
  --infer-dir ../SpeechNet_Test/speechnet_infer_BP_round1                # exp17: 87.78 %

# 2  BP single step
python3 deeployTrainingRunner_tiled_siracusa.py -t ../SpeechNet_Test/speechnet_train_BP_single_step \
  --n-steps 1 --n-accum 1 --num-data-inputs 2 --l2 1500000 $M -D BN_FROZEN_STATS=ON

# 3  ZO round 1 (2700 steps; ~12 h), then evaluate batch 2
python3 deeployMezoRunner_tiled_siracusa.py -t ../SpeechNet_Test/speechnet_train_ZO_round1 \
  --optimizer-dir ../SpeechNet_Test/speechnet_update_ZO_round1 \
  --n-steps 2700 --n-accum 4 --num-data-inputs 2 --eps 0.01 --lr 3e-6 --q 1 --seed 42 \
  --l2 2000000 $M -D BN_FROZEN_STATS=ON DUMP_WEIGHTS=ON
python3 experiments/headonly_ondevice_finetune/speechnet_accuracy_eval_untiled.py \
  --infer-dir ../SpeechNet_Test/speechnet_infer_ZO_round1                # exp18: 90.00 %

# 4  ZO single step
python3 deeployMezoRunner_tiled_siracusa.py -t ../SpeechNet_Test/speechnet_train_ZO_single_step \
  --optimizer-dir ../SpeechNet_Test/speechnet_update_ZO_single_step \
  --n-steps 1 --n-accum 1 --num-data-inputs 2 --eps 0.01 --lr 3e-6 --q 1 --seed 42 \
  --l2 2000000 $M -D BN_FROZEN_STATS=ON

# 6  QZO single step
python3 deeployMezoRunner_tiled_siracusa.py -t ../SpeechNet_Test/speechnet_train_QZO_single_step \
  --optimizer-dir ../SpeechNet_Test/speechnet_update_QZO_single_step \
  --n-steps 1 --n-accum 1 --num-data-inputs 2 --eps 0.01 --lr 1e-5 --q 1 --seed 42 \
  --l1 128000 --l2 2000000 --defaultMemLevel L2 --cores 8 -D BN_FROZEN_STATS=ON

# 7 / 10  block-0 conv on the Siracusa cluster (fused / unfused); the int32 pin is required
PIN="--input-type-map blocks.0.conv.bias_rqsadd=int32_t --input-offset-map blocks.0.conv.bias_rqsadd=0"
python3 deeployRunner_tiled_siracusa.py -t ../SpeechNet_Test/speechnet_fused_b0_cluster   --l2 1500000 $M $PIN  # exp5: 910,763
python3 deeployRunner_tiled_siracusa.py -t ../SpeechNet_Test/speechnet_unfused_b0_cluster --l2 1500000 $M $PIN  # exp3: 858,185
# add --profileMicrobenchmark for per-node counters

# --- GAP9: docker exec -it deeploy_gap9 bash ; source the three GAP9 SDK lines ; cd /app/Deeploy/DeeployTest
P="--l1 92000 --l2 1500000 --defaultMemLevel L2 --cores 8 --input-type-map blocks.0.conv.bias_rqsadd=int32_t --input-offset-map blocks.0.conv.bias_rqsadd=0"
python3 deeployRunner_tiled_gap9.py        -t ../SpeechNet_Test/speechnet_fused_b0_cluster   $P   # 8,  exp6 C_cl: 925,593
python3 deeployRunner_tiled_gap9_w_ne16.py -t ../SpeechNet_Test/speechnet_fused_b0_NE16      $P   # 9,  exp6 C:    541,345
python3 deeployRunner_tiled_gap9.py        -t ../SpeechNet_Test/speechnet_unfused_b0_cluster $P   # 10, exp6 A:    734,449
python3 deeployRunner_tiled_gap9_w_ne16.py -t ../SpeechNet_Test/speechnet_unfused_b0_NE16    $P   # 11, exp6 B:    379,969
```

A fixture outside `DeeployTest/` makes the runner print a warning ("outside base directory") and
generate into `TEST_<PLATFORM>/<fixture name>`; this is expected. Set `PYTEST_XDIST_WORKER=<tag>`
to give concurrent runs separate build directories.

## Regenerating

```bash
bash scripts/export_fixtures.sh all          # or individual targets: bp_round1 bp_single zo_round1 ...
docker exec agitated_hugle python3 /app/TrainDeeploy/SpeechNet_Test/scripts/crosscheck.py > logs/crosscheck.txt
```

`exports/` holds the raw Onnx4Deeploy output for the ZO/QZO fixtures (the exporter writes both graphs
into one directory; `pack_2step_fixture.py` splits them). `logs/` holds every export log.

### Exporter change made for the single-step fixtures

Before 2026-10-12 a single-step export could not reuse the round-1 window pool: the BP and ZO
exporters drew only as many windows as forwards requested (one), which fails the 9-class stratified
draw, and the QZO exporter ignored `--n-steps` and simulated a full pass over the pool. Onnx4Deeploy
now draws the full `--data-size` pool in all three modes and keeps only the windows the requested
steps consume; QZO honours an explicit `--n-steps`. Files: `Onnx4Deeploy/Onnx4Deeploy.py`
(`n_batches_explicit`), `onnx4deeploy/models/speechnet_exporter.py` (BP and ZO pool draw),
`onnx4deeploy/core/base_exporter.py` (QZO step count and pool), all marked `QW 2026-10-12`. Round-1
exports are unchanged: a BP round-1 re-export with the patched exporter is byte-identical to the
pre-patch one (`logs/patchcheck_bp_round1.log`), and the QZO single step reproduces exp19's first step.
